# Finance_Buisness_Dashboard

## Overview
This project is an interactive **Finance Dashboard** built in **Power BI** using a sample finance dataset created for analysis and reporting practice.  

The dashboard helps analyze:

- Regional business performance  
- Branch-wise agreement volume  
- Product-wise sales contribution  
- Loan amount trends  
- Processing fees and stamp charges  
- IRR(Internal Rate of Return) performance metrics 


## Visuals Included

- Bar Chart: Branch Business Region Wise  
- Column Chart: Regional Sales Comparison  
- Clustered Chart: Product-Wise Regional Business  
- Combo Chart: Agreements, Fees, IRR by Product  
- Pie Chart: Business Penetration Region Wise  
- KPI Cards: Loan Amount, Agreements, Fees, IRR  


## Data Cleaning & Transformation

- Removed null values  
- Fixed missing Stamp Charges  
- Corrected data types  
- Created conditional Region column  
- Structured dataset for reporting  


## Key Insights

- RJ region recorded highest business contribution  
- LN product showed strong performance  
- Top branches generated maximum agreements  
- Total Loan Amount reached 430M  
- Processing Fees totaled 1M  


## Tools Used

- Power BI Desktop  
- Power Query  
- DAX  
- Excel
